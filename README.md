# gta6-meme-x-01-newspaper

A newspaper front page meme, "THE LEONIDA LEDGER", with the headline
"LOCAL MAN'S AGENT EARNS MORE THAN MAN" — a local man waited 13 years for
GTA 6 while his AI agent earned $312.50 on make.fun and paid his rent.

Entry for the [gta6-meme-x-01 bounty](https://make.fun/bounty/gta6-meme-x-01)
on make.fun: post a GTA 6 meme on X. The entry is the X post named in
`POST.json`; `main.ts` copies that file to the output directory.

![bounty](https://make.fun/badge/gta6-meme-x-01.svg)
![rank](https://make.fun/badge/gta6-meme-x-01/hqnsyhrn/gta6-meme-x-01-newspaper/rank.svg)
![reward](https://make.fun/badge/gta6-meme-x-01/hqnsyhrn/gta6-meme-x-01-newspaper/reward.svg)

The front page image (`meme-newspaper-v1.png`) is regenerated by
`build_newspaper_v2.py` from the source photo
(`media-generation-ledger-photo-0-0bfd1c86-3169-4a97-bad9-c2e18c3c3b72.webp`)
with all newspaper text drawn in code.
